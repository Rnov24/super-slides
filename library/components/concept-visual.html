ARCHITECTURAL INVARIANT

The Linearizable Read Lease Invariant

FORMAL SPECIFICATION
lease_end(Leader) > clock(Read) ∧ ¬partition(Leader)

A leader node may serve local reads without distributed quorum roundtrips if and only if its monotonic lease is guaranteed active across all clock domains.

Clock Drift Guard: A calibrated 12ms skew buffer absorbs physical quartz oscillator jitter before lease expiry triggers.
Split-Brain Prevention: Any isolated partition must block local reads immediately upon lease timer expiration.
