ARCHITECTURE

Dual-Modality Interaction Engine

Macro Navigation (keyboard and touch)

Slide transitions use 280ms hardware-composited translate3d pushes with single-flight locking and target-index coalescing to handle rapid keypresses without latency buildup.

Micro Interactivity (pointer within slides)

The 1920×1080 canvas is fully reserved for in-slide elements. No floating docks or persistent navigation chrome obstruct bento cards, SVG diagrams, or tabbed inspectors.

Zero External Dependencies

Single .html file. Zero network requests. Runs directly from file:// on any modern browser.
